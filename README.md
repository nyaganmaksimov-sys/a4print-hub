# A4PRINT HUB

Единая внутренняя система учёта и управления для А4-Принт и 3D-ARTPRINT.

## Основные возможности

- общая база клиентов;
- товары, услуги, склад и остатки;
- единый учёт заказов и производство;
- касса и POS;
- кабинет партнёра;
- мобильный интерфейс;
- единый встроенный чат персонала и партнёров;
- уведомления, отчёты и аналитика;
- роли и права сотрудников.

## Архитектура

```text
Admin HUB ───────┐
Partner CRM ─────┼── shared UI / API ── База данных
POS / Kassa ─────┤
Mobile ──────────┘
```

GitHub хранит код и документацию. Клиентские данные и серверные секреты не должны храниться в репозитории.

## Структура проекта

```text
admin/      внутренняя панель A4PRINT HUB
partner/    кабинет и CRM партнёра
shared/     общие компоненты и логика нескольких интерфейсов
api/        серверный API
mobile/     мобильная рабочая поверхность
pos/        POS-приложение
kassa/      кассовая рабочая поверхность
courier/    интерфейс курьера
database/   схема и неизменяемая история миграций БД
docs/       актуальная архитектура и эксплуатационная документация
```

## Чат

Отдельного приложения Chat больше нет. Сообщения встроены непосредственно в A4PRINT HUB и Partner CRM и используют общее ядро в `shared/`.

Каноническая схема мессенджера описана в [`docs/CHAT_ARCHITECTURE.md`](docs/CHAT_ARCHITECTURE.md).

## Правило изменений интерфейса

Не добавлять рядом с рабочим файлом ещё один `*-new`, `*-final` или очередной `*-vN` без плана миграции. Сначала определить текущую точку входа, переключить её на новую реализацию и только затем удалять подтверждённо неиспользуемый код. Миграции БД по названию «старые» не удаляются.
