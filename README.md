# A4PRINT HUB

Единая внутренняя система учёта и управления для А4-Принт и 3D-ARTPRINT.

## Цели

- общая база клиентов;
- общий склад и остатки;
- товары и услуги;
- единый учёт заказов;
- производственные задания;
- каталог 3D-моделей;
- внутренние сообщения;
- уведомления;
- отчёты и аналитика;
- роли и права сотрудников.

## Архитектура

```text
А4-Принт ───────┐
                ├── API ── База данных
3D-ARTPRINT ────┘          │
                           └── Admin / HUB
```

GitHub хранит код и документацию. Клиентские данные и секреты не хранятся в репозитории.

## Структура проекта

```text
docs/       архитектура и спецификация
database/   схема БД и миграции
api/        серверный API
admin/      внутренняя панель управления
```

## Этапы

1. Спроектировать БД.
2. Подключить защищённую БД и авторизацию.
3. Сделать товары, услуги и склад.
4. Сделать заказы.
5. Подключить 3D-ARTPRINT.
6. Подключить А4-Принт.
7. Добавить производство и сообщения.
8. Добавить отчёты.
