A4PRINT HUB

Пошаговая инструкция для администратора, менеджера, производства, склада, кассира и партнёров.

1. Вход и роли

Вход в HUBВход POSВход партнёра

Роли

  • ADMIN — полный административный доступ.
  • MANAGER — клиенты, заказы, партнёры и рабочий стол менеджера.
  • WAREHOUSE — склад, номенклатура и движения материалов.
  • PRODUCTION — выполнение производственных заданий.
  • VIEWER — просмотр разрешённой информации.
  • POS_OPERATOR — отдельная касса/POS.
Каждый сотрудник входит под собственной учётной записью. Не передавайте общий пароль нескольким сотрудникам.

2. Рабочий стол менеджера

  1. Откройте «Рабочий стол менеджера».
  2. Выберите или создайте клиента.
  3. Выберите услугу предварительного заказа.
  4. Укажите тираж, размеры, материал, цвет и другие параметры.
  5. Проверьте стоимость. Не вводите неподтверждённую цену вместо расчётной.
  6. Добавьте комментарий и макет, если он нужен.
  7. Создайте заказ и проверьте его в разделе «Заказы».
Рабочий стол менеджера предназначен прежде всего для заказных услуг: полиграфия, сувенирная продукция, широкоформатная и 3D-печать и другие работы с предварительным оформлением.

3. Работа с заказами

Новый→ Подтверждён→ В работе→ Готов→ Завершён
  1. Найдите заказ по номеру, клиенту или фильтру.
  2. Откройте карточку и проверьте состав, параметры, сумму, комментарии и файлы.
  3. После согласования переведите заказ в подтверждённый статус.
  4. При фактическом запуске работы установите «В работе».
  5. После изготовления — «Готов».
  6. После выдачи/окончательного закрытия — «Завершён».
Не отмечайте заказ завершённым до фактического выполнения и выдачи.

4. Клиенты

Раздел хранит общую клиентскую базу. Перед созданием нового клиента сначала выполните поиск, чтобы не создавать дубль. Заполняйте имя/название, телефон, e-mail и другие доступные реквизиты. История заказов должна оставаться связанной с одной карточкой клиента.

5. Партнёры

Добавление партнёра

  1. Откройте «Партнёры» → «Добавить партнёра».
  2. Заполните организацию, контакт, телефон и e-mail.
  3. Создайте данные входа партнёра.
  4. Укажите скидку и условия оплаты, если они согласованы.
  5. Сохраните и передайте партнёру адрес его кабинета.

Партнёр заказывает у A4PRINT

Партнёр выбирает услугу из нашего партнёрского каталога, создаёт заказ и прикладывает макеты. Заказ поступает в общую базу HUB.

A4PRINT заказывает у партнёра

Партнёр сначала формирует свой прайс для A4PRINT. Сотрудник HUB выбирает партнёра, его услугу, количество, параметры, комментарий и файлы и отправляет заказ.

6. Личный кабинет партнёра

  1. Войти через отдельную страницу партнёра.
  2. В блоке «Новый заказ в A4PRINT» выбрать услугу, количество и параметры.
  3. При необходимости приложить файлы и отправить заказ.
  4. В «Мои заказы в A4PRINT» отслеживать свои заказы.
  5. В «Мой прайс для A4PRINT» добавить услуги, которые партнёр выполняет для нас.
  6. В «Заказы от A4PRINT» принять поступивший заказ и менять рабочий статус по мере выполнения.
Партнёр видит только данные, доступные его партнёрской учётной записи.

7. Макеты и файлы

Макеты прикрепляются к соответствующему заказу. Перед отправкой убедитесь, что файл относится именно к этому заказу. Для партнёрского обмена используется закрытое хранилище: доступ к файлам определяется правами на заказ.

8. Склад и номенклатура

  • Номенклатура содержит товары, материалы, услуги, готовые изделия и другие позиции.
  • При поступлении оформляйте приход, при продаже/использовании — соответствующее движение.
  • Списание делайте только по фактической причине.
  • Контролируйте минимальные остатки и не исправляйте количество без основания.

9. Производство

  1. Откройте поступившую работу.
  2. Проверьте параметры и файлы до начала производства.
  3. Переведите работу в фактический рабочий статус.
  4. После изготовления проверьте результат и отметьте готовность.
  5. При проблеме не закрывайте заказ — зафиксируйте причину и сообщите менеджеру.

10. POS / касса

Открыть POS
  1. Войти под ролью POS_OPERATOR или разрешённой административной ролью.
  2. Открыть кассовую смену.
  3. Добавить позиции продажи и при необходимости выбрать клиента.
  4. Проверить сумму и провести продажу.
  5. Возврат проводить через раздел возвратов, а не отрицательной продажей.
  6. В конце рабочего периода закрыть смену.
Кассовые операции попадают в общую базу. Не создавайте тестовые продажи в рабочей смене без необходимости.

11. Внутренние сообщения

Используйте раздел «Сообщения» для рабочих вопросов между сотрудниками. Важные сведения по конкретному заказу также фиксируйте в самом заказе, чтобы они не потерялись в переписке.

12. Пользователи и операторы

Создание сотрудников и назначение ролей выполняет администратор. Давайте сотруднику только те права, которые нужны для его работы. Для кассира используйте роль POS_OPERATOR.

13. Настройка расположения блоков

  1. Нажмите «Настроить блоки».
  2. Перетащите доступные рабочие карточки за кнопку перемещения.
  3. Нажмите «Готово».
  4. Порядок сохраняется в браузере для текущей страницы.
  5. Кнопка «Сбросить» возвращает исходное расположение.

14. Типовые рабочие сценарии

Обычный заказ клиента

Клиент → менеджер создаёт заказ → согласование → производство → готовность → оплата/выдача → завершение.

Партнёр заказывает у нас

Партнёрский кабинет → заказ + файлы → HUB → менеджер/производство → готовность → партнёр видит статус.

Мы заказываем у партнёра

Прайс партнёра → HUB «Партнёры» → заказ + файлы → кабинет партнёра → принятие → выполнение → готовность.

15. Что делать при ошибке

  • Не входит: проверить e-mail, пароль, роль и активность пользователя.
  • Нет раздела: проверить роль и права доступа.
  • Не создаётся заказ: проверить обязательные поля и сообщение об ошибке.
  • Не загружается файл: проверить размер/соединение и повторить для правильного заказа.
  • Партнёр не видит заказ: проверить, какой партнёр указан заказчиком или исполнителем.
  • POS не работает: проверить авторизацию, роль оператора и состояние смены.
При технической ошибке сохраните текст сообщения и страницу, на которой она возникла. Это значительно ускоряет исправление.
