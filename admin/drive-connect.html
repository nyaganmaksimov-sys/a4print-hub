Как это работает

После подключения файлы из внутренних чатов будут загружаться в папку A4PRINT HUB / Чаты. Сотрудники скачивают их через HUB — прямой публичный доступ к файлам не требуется.
  • 1
    Администратор подключает Google‑аккаунт
    Подключение выполняется один раз для всей организации.
  • 2
    Сотрудник нажимает 📎 в чате
    HUB загружает файл в Google Drive и сохраняет связь с сообщением.
  • 3
    Доступ проверяет A4PRINT HUB
    Скачивание проходит через защищённую серверную функцию с авторизацией сотрудника.

Нужна первичная настройка Google Cloud

Код интеграции уже установлен. Осталось создать OAuth 2.0 Web Client для A4PRINT HUB и добавить его Client ID / Client Secret в секреты Edge Functions.

После добавления секретов GOOGLE_DRIVE_CLIENT_ID и GOOGLE_DRIVE_CLIENT_SECRET перезагрузи эту страницу — появится кнопка подключения.
