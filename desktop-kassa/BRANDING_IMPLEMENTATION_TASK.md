# A4-Касса — задание на внедрение фирменного логотипа и иконки

## Цель
Полностью заменить временные/искажённые логотипы и стандартную Electron-иконку на единый фирменный стиль A4-Касса.

## Утверждённые ассеты
- `kassa/assets/a4-kassa-logo.svg` — горизонтальный логотип для интерфейса.
- `kassa/assets/a4-kassa-icon.svg` — компактная иконка для web/PWA.
- `desktop-kassa/assets/app-icon.b64` — исходник фирменной иконки desktop в PNG/base64.
- На сборке Windows из него создаётся `desktop-kassa/build/icon.ico`.

## Требования к интерфейсу
1. В левом сайдбаре использовать только горизонтальный логотип A4-Касса; не растягивать.
2. В верхней панели использовать тот же логотип с `object-fit: contain`.
3. На экране авторизации использовать горизонтальную версию без белой «карточки внутри карточки».
4. Не использовать старый `a4-kassa-brandbook.jpg` после миграции.
5. При сворачивании меню показывать компактную иконку A4-Касса, а не обрезанный горизонтальный логотип.
6. Сохранить исходные пропорции всех логотипов.

## Требования к Windows-приложению
1. Иконка окна BrowserWindow должна быть A4-Касса.
2. Иконка EXE, ярлыка рабочего стола, меню Пуск и NSIS-установщика должна быть A4-Касса.
3. Windows icon должен содержать размеры 16, 24, 32, 48, 64, 128 и 256 px.
4. `electron-builder` должен использовать `build/icon.ico`.
5. Иконка должна создаваться до `electron-builder`, чтобы CI и локальная сборка всегда были воспроизводимы.

## Проверка
- `npm run check` проходит.
- `npm run dist:win` создаёт NSIS без fallback Electron icon.
- После установки значок A4-Касса виден в заголовке окна, панели задач, ярлыке и меню Пуск.
- На 100%, 125%, 150% и 200% Windows scaling значок остаётся чётким.
- В интерфейсе логотип не сплющивается и не обрезается.

## Запреты
- Не менять финансовую логику кассы.
- Не менять логику смен, продаж, возвратов и синхронизации.
- Не подменять фирменную иконку логотипом A4PRINT HUB.
