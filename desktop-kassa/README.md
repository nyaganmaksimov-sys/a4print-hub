# A4PRINT KASSA Desktop

Windows-оболочка для рабочей A4PRINT KASSA 2.1.

## Разработка
`npm install`
`npm start`

## Windows installer
Поместить фирменную иконку брендбука A4-Касса в `assets/kassa.ico`, затем:
`npm run dist:win`

Результат: `release/A4PRINT-KASSA-Setup-2.1.2.exe`.

Приложение использует production KASSA по адресу https://a4print-hub.ru/kassa/ и сохраняет существующую архитектуру HUB/МойСклад и локальную очередь браузерного профиля Electron.


## Автоматические обновления

Начиная с версии 2.1.3, установленная A4PRINT KASSA проверяет стабильный канал обновлений автоматически и также позволяет запустить проверку вручную из раздела «Настройки».

Перед скачиванием оператор видит номер новой версии и список изменений. После загрузки доступна команда «Перезапустить и установить». После успешной установки при первом запуске показывается окно «Что нового»; оно отображается один раз для каждой версии.

Единый журнал изменений версии хранится в `update-notes.json`. Его `version` должен совпадать с версией `package.json`. GitHub Actions публикует установщик, `latest.yml`, blockmap и `update-notes.json` в стабильный release-канал `kassa-desktop`.


## Компактная навигация

В 2.1.4 боковая панель кассы уменьшена до 174 px, рабочее меню имеет собственную вертикальную прокрутку, используется основной фирменный логотип A4PRINT KASSA, а раздел «Печати и штампы» получил отдельную SVG-иконку штампа.
